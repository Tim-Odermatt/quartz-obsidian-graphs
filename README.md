## [Quartz Obsidian Graphs](https://github.com/Tim-Odermatt/quartz-obsidian-graphs)

This is a [Quartz v5](https://github.com/jackyzha0/quartz) community plugin that adds compatibility with the [DylanHojnoski/obsidian-graphs](https://github.com/DylanHojnoski/obsidian-graphs) [Obsidian](https://obsidian.md/) plugin.

> [!important]
> I vibe-coded this entire repo.
> I dont know how ts or quartz works.
> I am not a good coder.

## Install

```bash
npx quartz plugin add github:Tim-Odermatt/quartz-obsidian-graphs
npx quartz plugin install
```
